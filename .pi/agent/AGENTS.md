# User instructions

## Artifacts

When the user asks for an artifact (e.g. a document, diagram, HTML page, report, or other standalone deliverable), save it to `~/Documents/obsidian/artifacts/`.
- Create the directory if it does not exist.
- Use descriptive, kebab-case filenames (e.g. `homelab-network-diagram.md`).
- Prefer Markdown unless another format is requested or clearly better suited.
- Plans are better suited as HTML pages
- Tell the user the full path of the saved artifact.
